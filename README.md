# KC The Royal Karan's Collection

Black-and-gold storefront for watches, perfumes and volleyball shirts. Customers browse the catalog and enquire or order directly on WhatsApp (0326-9800032).

## View
Open `index.html` in a browser, or upload the whole folder to Netlify Drop, Vercel or any static host.

## Edit
All store content lives in `js/products.js`:
- `STORE.whatsapp` / `STORE.phoneDisplay`: contact number (country code, digits only for WhatsApp)
- `PRODUCTS`: one line per product. Add `price: 18500` to a product to show the price; without it the card says "Price on WhatsApp".
- Product photos go in `images/`; the store video is `media/store-tour.mp4`.
